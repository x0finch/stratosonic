# Skills

Engineering & productivity skills vendored from
[mattpocock/skills](https://github.com/mattpocock/skills) ("Skills for Real Engineers").

These are ordinary files you own and can edit. To pull upstream updates, either
re-vendor from the repo or use the upstream CLI (`npx skills@latest add mattpocock/skills`).

Before first use of the engineering skills, run `/setup-matt-pocock-skills` once in this
repo to configure the issue tracker, triage labels, and doc layout the skills assume.
